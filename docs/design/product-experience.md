# 单机产品体验约定

## 核心路径

首页先选择模式。人机对局和本地双人点击后打开开局面板，取消不创建棋局。
人机默认每方 15 分钟、普通难度，只有展开高级设置后才出现搜索参数。
本地双人只需要选择用时；AI 对战独立配置双方难度和落子间隔。
已有未完成棋局显示“继续上局”，直接恢复原来的局面和棋钟。
手机首页优先展示操作入口，棋盘预览放在入口之后。

## 视觉约定

- 首页、设置、对局、拆解共用 `AppPalette`、`AppBackdrop` 和 `AppGlassSurface`。
- 棋盘资源保留原始颜色、棋线与锚点。背景图低透明度融入应用底色，避免深色背景与浅色面板形成强烈割裂。
- 桌面设置固定左侧导航，右侧内容从顶部开始，表单沿可用宽度展开；超宽窗口限制阅读宽度。
- 主题选择展示真实棋盘缩略图；对局立即应用，返回首页后预览使用保存的主题。
- 难度与动画分段选项填满所在组的宽度，避免在大面板中央漂浮。
- 普通运行隐藏调试浮标。使用 `--dart-define=UI_DEBUG=true` 显式开启 UI 调试构建。

## 新手与设置

首页提供带文字的象棋规则入口。难度名称在开局与设置中保持一致：入门、普通、较强。
搜索深度、基础思考时间收进高级设置，允许恢复当前难度的推荐参数。
基础思考时间是时间分配的参考，有棋钟时电脑仍根据剩余时间调整；不把它描述为固定的每步上限。
未提供的背景音乐不展示为不可用的设置项。

## 验收与截图

`test/product_experience_test.dart` 覆盖桌面和手机的开局、取消、设置、高级参数展开和本地双人用时。
`test/chess_page_responsive_test.dart` 验证主题即时切换、设置顶部对齐和棋盘响应布局。

运行基础验收：

```sh
fvm flutter analyze --no-fatal-infos
fvm flutter test
```

本机导出真实 Flutter 控件的布局截图：

```sh
UI_REVIEW_DIR=/tmp/chess-ui fvm flutter test test/product_experience_test.dart
```

截图用于检查空间、文字、控件和资产布局；仍需在 macOS 窗口与移动设备上验收键盘、触控、窗口缩放和实际动效。
